# ObsidianVault —— 项目知识与面试笔记仓库

> 本仓库用于统一管理 `claims_review_agent` / `EduAgent` / `KnowForge` 的项目笔记、
> LangGraph / RAG 学习笔记，以及 Agent&RAG 开发岗的七段式面试简历素材。
> 由 WorkBuddy 自动搭建（2026-08-29）。

## 目录结构

| 目录 | 用途 |
|---|---|
| `00-Inbox/` | 随手记、临时想法，定期整理归档 |
| `10-Projects/` | 三个项目各自的笔记（claims_review_agent / EduAgent / KnowForge） |
| `20-Interview/` | 七段式简历素材、面试题、项目亮点梳理 |
| `30-Notes/` | LangGraph / RAG / agent 框架学习笔记、调试备忘 |
| `40-Templates/` | Templater 模板（简历、会议纪要、周报等） |
| `99-Archive/` | 已完成 / 废弃内容、附件 |

## 已安装的社区插件

（由 WorkBuddy 从 GitHub 下载，详见 `.obsidian/plugins/`，启用列表见 `.obsidian/community-plugins.json`）

- **Dataview** —— 用 SQL 风格语法按标签/元数据聚合笔记列表
- **Excalidraw** —— 直接在笔记里画架构图、流程图（比截图好维护）
- **Templater** —— 一键套用模板（简历、周报）
- **Obsidian Git** —— 把 vault 自动备份到 Git 仓库
- **Calendar** —— 日历视图，配合每日笔记
- **Periodic Notes** —— 日/周/月笔记模板
- **Advanced Tables** —— 可视化编辑 Markdown 表格
- **Kanban** —— 看板视图管理任务

## 如何打开

1. 打开 Obsidian 桌面端
2. 「打开本地仓库」→ 选择 `E:\Sync\ObsidianVault`
3. 首次打开如提示「启用社区插件」，确认即可（插件文件已就位）
